# 🎮 Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. Play against the computer, keep track of scores, and enjoy a clean and responsive interface.

---

## 🚀 Features

- ✋ Play Rock, Paper, or Scissors
- 🤖 Random computer choice
- 🏆 Real-time score tracking
- 🎯 Displays win, lose, or draw messages
- 💻 Responsive and beginner-friendly design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## 🎮 How to Play

1. Click on **Rock**, **Paper**, or **Scissors**.
2. The computer will randomly select its move.
3. The winner is decided based on the game rules:
   - Rock beats Scissors
   - Scissors beats Paper
   - Paper beats Rock
4. Scores are updated automatically after each round.
